Overriding: It necessarily requires inheritance.
The method name is same in the base and child class,
 it may or may not be virtual in the base class, 
and method can be created as new or override depending on 
whether the method in the base class is virtual or not.


new(Method hiding-Compile time):redefine method in child class,
Hides the parent method, can only be used when inheritance is there.
Separate version of every code, it has nothing to do with the base class, then write "new".


override(Runtime Polymorphism):redefine method in child class,can only be used when inheritance is there,
Override replaces parent implementation with child implementation.
Parent reference can call child reference,
 override can be used only if method is virtual in the base or it is abstract.
example: CalculateSalary(), the calculation way will be different for each type(mgr,srmgr,direction,asso director).
class Employee
{
CalculateSalary()
{

}
}
class Manager:Employee
{
override CalculateSalary()
{
//super===base
base.CalculateSalary() +++
}
}
